# vrm-avatar.js プログラム仕様書

[vrm-avatar.js](file:///c:/Users/owner/Documents/lab/Antigravity/alpha-synapse/src/vrm-avatar.js) は、3Dアバター（VRMモデル）のロード、表情ブレンドシェイプの変更、骨格関節（スケルトン）の回転操作、および「生きているようなアニメーション（呼吸、瞬き、視線追従、リップシンク、ポージング）」を制御するクラス `VRMAvatar` を定義するスクリプトである。

---

## 1. 主要データ構造

### 1.1 感情・状態別ポーズ設定値（`POSES`）
各関節の初期位置からの相対回転量（ラジアン）を定義している。関節がねじれたり不自然にちぎれるのを防ぐため、これらはすべてクォータニオンと掛け合わせるベース角度として使用される。

| ポーズ名 | 対象関節 | 設定値（XYZ回転角のラジアン値） |
| :--- | :--- | :--- |
| **`idle`** | 左右アーム、ハンド、背骨 | 基本待機姿勢。腕は自然に下がり、背骨はニュートラル。 |
| **`happy`** | 左右アーム、ハンド、背骨 | 喜びのポーズ。腕が少し上がり、肘が90度曲がる。背骨はわずかに後ろに反る。 |
| **`angry`** | 左右アーム、ハンド、背骨 | 怒りのポーズ。両肘を張って前かがみ気味になる。 |
| **`sad`** | 左右アーム、ハンド、背骨 | 悲しみのポーズ。肩がすぼまり、うつむき加減になる。 |
| **`relaxed`** | 左右アーム、ハンド、背骨 | リラックスポーズ。アシンメトリー（非対称）な構えで、背骨も少し傾く。 |
| **`surprised`** | 左右アーム、ハンド、背骨 | 驚きのポーズ。両腕が大きく開かれ、手が前を向く。 |
| **`thinking`** | 左右アーム、ハンド、背骨 | 思考中のポーズ。右手が顎の近くに上がり、背骨が少しねじれる。 |
| **`teasing`** | 左右アーム、ハンド、背骨 | からかいポーズ。上半身を右にわずかにひねり、右腕に軽いアクション。アイドル能動発話時に使用。 |
| **`greeting`** | 左右アーム、ハンド、背骨 | 挨拶ポーズ。左腕を軽く上げて手を振るような仕草。時間帯別ウェルカム発話時に使用。 |

## 2. クラス `VRMAvatar` 仕様

### 2.1 主要プロパティ

| プロパティ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `currentVRM` | `VRM` | pixiv/three-vrm で生成されたVRMモデルの実体。未ロード時は `null`。 |
| `loader` | `GLTFLoader` | VRMLoaderPlugin を登録済みの GLTFLoader インスタンス。 |
| `holoGroup` | `THREE.Group` | アバター未ロード時に表示されるサイバー風のワイヤーフレームおよび浮遊粒子。 |
| `breathingSpeed` | `number` | 呼吸の速さを示す係数。デフォルトは `2.0`。 |
| `breathingAmount`| `number` | 呼吸時の胸の膨らみ（回転角）の大きさを示す係数。デフォルトは `0.015`。 |
| `blinkInterval` | `number` | 次に瞬きをするまでの秒数。乱数によって毎回変動する。 |
| `isBlinking` | `boolean` | 現在まぶたを閉じたり開いたりする動作の最中かどうかのフラグ。 |
| `lipSyncActive` | `boolean` | 現在リップシンク処理が有効（アバターがセリフ発話中）かどうかのフラグ。 |
| `currentVowel` | `string` | 現在アバターが口の形にする母音（`'aa'`, `'ih'`, `'ou'`, `'ee'`, `'oh'`）。 |
| `defaultRotations`| `object` | ロード時に記録した肩、肘、手首、背骨などの初期回転クォータニオン情報。 |

---

### 2.2 主要メソッド

#### `loadModel(arrayBuffer)`
*   **処理概要**: アップロードされたVRMファイルのバイナリデータをパースし、シーンに追加する。その後、頭部、首、背骨、両腕、両肘、両手首のボーンを抽出し、初期回転クォータニオンを `defaultRotations` に退避する。
*   **引数**:
    *   `arrayBuffer` (`ArrayBuffer`): VRMファイルのバイナリデータ
*   **戻り値**: `Promise<VRM>`: パースされた VRM インスタンス
*   **呼び出す外部関数**:
    *   `GLTFLoader.parse()`
    *   `clearCurrentModel()`

#### `clearCurrentModel()`
*   **処理概要**: シーンから現在のアバターモデルを取り除き、ジオメトリやマテリアル、テクスチャのメモリを明示的に解放（`.dispose()`）して、ホログラムプレースホルダーを再表示する。
*   **引数**: なし
*   **戻り値**: なし

#### `setExpression(name, value)`
*   **処理概要**: アバターの表情またはリップシンクのブレンドシェイプ強度を設定する。VRM 0.x (`blendShapeProxy`) および VRM 1.x (`expressionManager`) のAPIの差異を内部で自動判定して実行する。
*   **引数**:
    *   `name` (`string`): 表情名（例: `'happy'`, `'blink'`, `'aa'`, `'ih'`）
    *   `value` (`number`): ウェイト (0.0 〜 1.0)
*   **戻り値**: なし

#### `updateLipSync(delta)`
*   **処理概要**: アバター発話中、ミリ秒ごとにサイン波を用いて顎の開き強度（リップシンクウェイト）を計算する。現在の母音 `currentVowel` をウェイトに応じて線形補間（LERP）し、他の母音ブレンドシェイプをゼロにリセットして口の形を設定する。
*   **引数**:
    *   `delta` (`number`): 前フレームからの経過秒数
*   **戻り値**: なし
*   **呼び出す内部関数**: `setExpression()`

#### `updateBlinking(delta)`
*   **処理概要**: ランダムな間隔で瞬きをトリガーする。まぶたが閉じる（ウェイトが 0.0 → 1.0）動作と、開く（1.0 → 0.0）動作を `blinkDuration` (150ms) 内で滑らかに行い、`blink` 表情に適用する。
*   **引数**:
    *   `delta` (`number`): 前フレームからの経過秒数
*   **戻り値**: なし
*   **呼び出す内部関数**: `setExpression()`

#### `updateLookAt(delta)`
*   **処理概要**: アバターの視線および首の向きをターゲットに追随させる。
    *   **デスクトップ**: マウス位置に応じて追従。
    *   **WebXR (VR/AR)**: ヘッドセット（カメラ）のワールド座標を算出し、アバターの正面から見た相対的な偏角（Yaw/Pitch）を算出して首（Neck）と頭（Head）の骨を目標方向に補間回転する。
*   **引数**:
    *   `delta` (`number`): 前フレームからの経過秒数
*   **戻り値**: なし

#### `updatePose(delta)`
*   **処理概要**: アバターの骨格ポーズを、現在のアクティブポーズに定義された角度（`POSES`）に補間する。このとき、もし発話中（`lipSyncActive === true`）であれば、両腕・両肘に微小なランダムサイン波による「身振り手振り」のオフセット回転を上乗せしてクォータニオンを合成する。
*   **引数**:
    *   `delta` (`number`): 前フレームからの経過秒数
*   **戻り値**: なし

#### `update(delta)`
*   **処理概要**: 毎フレームのアップデート処理。VRMがロードされている場合は、背骨への「緩やかな呼吸のサイン波揺らぎ」の付与、全身のポーズ補間、瞬き更新、LookAt更新、リップシンク更新、およびVRMスプリングボーンの物理演算更新を順に実行する。VRM未ロード時はホログラムワイヤーフレームを回転・拡大縮小させる。
*   **引数**:
    *   `delta` (`number`): 前フレームからの経過秒数
*   **戻り値**: なし
*   **呼び出す外部・内部関数**:
    *   `updatePose()`
    *   `updateBlinking()`
    *   `updateLookAt()`
    *   `updateLipSync()`
    *   `currentVRM.update()`

## 3. 関節ねじれバグ防止のアルゴリズム

```
【関節のクォータニオン相対回転合成】

 1. モデルロード時:
    各主要関節の初期回転角度（Tポーズ等の元データ）を退避
    (defaultRotations.leftUpperArm = quaternion.clone())

 2. ポーズ適用時 (updatePose):
    POSES に定義された相対角度（Euler: XYZ）を取得
    もし発話中であれば、時間経過(time)に応じたランダム揺らぎ（身振り手振り）を足し算
    (Euler = baseRotation + speakOffset)
    
 3. クォータニオン変換と合成:
    相対オイラー角をクォータニオンに変換
    (poseRelativeQuat = setFromEuler(Euler))
    
    初期の腕の角度に対して、相対的な曲げ角度を【掛け算】でブレンド
    (targetQuat = defaultRotations.leftUpperArm ✖ poseRelativeQuat)
    
 4. スプライン補間 (Slerp):
    前フレームの回転から、目標回転（targetQuat）まで毎フレーム滑らかに遷移
    (leftUpperArm.quaternion.slerp(targetQuat, lerpSpeed * delta))
```
