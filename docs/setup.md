# 3. 環境構築とトラブルシューティング

この章では、本アプリをあなたのパソコン（ローカル環境）で起動し、ローカルAI（Ollama）と通信させるための具体的な手順と、よくある通信エラーの解決法を学びます。

---

## 🛠️ 開発環境の立ち上げ手順

まずは、アプリを起動するためのコマンド操作です。黒い画面（ターミナル / コマンドプロンプト）に慣れていない方でも、順を追って進めれば大丈夫です。

### 1. 依存パッケージのインストール
ターミナルを開き、プロジェクトのフォルダ（`alpha-synapse`）に移動した状態で、以下のコマンドを実行します。

```bash
npm install
```
- **何をしているのか？**: カタログファイルである `package.json` を Node.js（npm）が読み込み、3Dアバターを描画するための Three.js や、Vite 開発ツールなどをインターネットからダウンロードして、`node_modules` というフォルダに自動保存します。

### 2. ローカル開発サーバーの起動
インストールが完了したら、以下のコマンドを実行します。

```bash
npm run dev
```
- **何をしているのか？**: Vite があなたのパソコンの中に一時的な「ローカルWebサーバー」を立ち上げます。
- 起動すると、ターミナルに `http://localhost:3000` のようなアドレスが表示され、ブラウザが自動的に起動してアプリの画面が開きます。

## 🛑 超難所：CORS 制限と Mixed Content の謎

ローカルAI（Ollama）を有効にして同期しようとした時、**"Failed to fetch"（接続失敗）** というエラーに直面することが非常によくあります。これはブラウザの「セキュリティ規制」が原因です。

```
【通信を邪魔するセキュリティ規制】

 🔒 CORS制限:
   [ブラウザ (localhost:3000)] ─── 接続要求 ───> 🖥️ [Ollama (127.0.0.1:11434)]
                                                    │ (Ollama側が許可を返さないと...)
                                                    ▼
                                            ブラウザが通信を遮断！

 🌐 Mixed Content (混在コンテンツ) 制限:
   [本番デモサイト (HTTPS)] ─── 接続不可 ───> 🖥️ [ローカルのOllama (HTTP)]
                                                    │ (安全なサイトから、暗号化されていない
                                                    │  ローカルサービスへの接続は禁止)
                                                    ▼
                                            ブラウザが通信を遮断！
```

### 1. CORS 制限とは？
ブラウザは安全のため、「あるサイトから、別のサーバーのデータへ勝手にリクエストを送る」ことを制限しています。
Ollamaは通常、ローカルの `http://localhost:11434` で動いていますが、ブラウザ上のアプリ（`http://localhost:3000`）から届いたリクエストに対して、Ollamaが「許可しますよ」という返事（CORSヘッダー）を返さない限り、ブラウザは通信をブロックしてしまいます。

- **対策**: Ollama 起動時に、「どこからのアクセスも許可する（オリジン自由 `*`）」という設定を与えます。

### 2. Mixed Content（混在コンテンツ）制限とは？
インターネット上の安全なWebサイト（`https://alpha-xr.org` のように **HTTPS** から始まるアドレス）から、あなたのパソコンの暗号化されていないサービス（`http://localhost:11434` のように **HTTP** から始まるアドレス）へ通信することは、セキュリティ上禁止されています。

- **対策**:
  - **一番簡単な解決策**: 本番サイトを使うのではなく、上で実行した `npm run dev` によるローカル環境（`http://localhost:3000` から始まる **HTTP** のアドレス）でアプリを開くことで、この規制を回避できます。
  - **Quest 3などのVRゴーグルで遊びたい場合**: 後述のローカルIPの設定、または Cloudflare Workers などのプロキシを経由させる必要があります。

## 💻 OllamaのCORS（アクセス許可）設定手順

Ollamaへリクエストを通すために、環境変数 `OLLAMA_ORIGINS` を `*`（すべて許可）に設定します。お使いのOSに合わせて設定を行ってください。

### 💻 Windows の場合
Windows では「システム環境変数」という場所に設定を登録します。

1. **システムのプロパティを開く**:
   - `Win + R` キーを同時に押し、名前欄に `sysdm.cpl` と入力して「OK」をクリックします。
2. **環境変数を開く**:
   - 上部の「詳細設定」タブをクリックし、一番下にある「環境変数...」ボタンをクリックします。
3. **新規変数を追加する**:
   - 「システム環境変数」側の「新規...」ボタンをクリックします。
   - **変数名**: `OLLAMA_ORIGINS`
   - **変数値**: `*`
   - 入力したら「OK」をクリックし、開いているすべての設定画面を「OK」で閉じます。
4. **Ollamaの完全終了と再起動**:
   - **【最重要】** 設定を反映させるため、タスクバー（右下の時計の横）にある **Ollamaの黒いラマのアイコンを右クリックし、「Quit Ollama」をクリックして完全に終了** させます。
   - その後、スタートメニューから通常通り Ollama を起動し直します。

### 🍎 macOS の場合
Macでは、ターミナルから環境変数を指定してアプリを起動します。

1. Ollama アプリが起動している場合は、メニューバーから完全に終了（Quit）させます。
2. ターミナルを開き、以下のコマンドを入力して実行します。
   ```bash
   OLLAMA_ORIGINS="*" open -a Ollama
   ```
- **何をしているのか？**: 「他の場所からのアクセスを全部許可する(`*`)」という設定（環境変数）を持たせた状態で、Ollama アプリを起動しています。

### 🐧 Linux の場合
Linux（Ubuntuなど）では、システムサービスの設定を編集します。

1. 以下のコマンドを実行して設定エディタを開きます。
   ```bash
   sudo systemctl edit ollama.service
   ```
2. 開いた画面に以下を追記して保存し、エディタを閉じます。
   ```ini
   [Service]
   Environment="OLLAMA_ORIGINS=*"
   ```
3. 設定を読み込み直し、サービスを再起動します。
   ```bash
   sudo systemctl daemon-reload
   sudo systemctl restart ollama
   ```

## 🥽 Meta Quest 3 等の VR ゴーグルから接続する手順

VR/ARゴーグルでプレイする場合、ゴーグル内のブラウザで `localhost` にアクセスすると、**「ゴーグル自身」**を指してしまい、PCで動いている Ollama に接続できません。

```
【VRゴーグル接続時の仕組み】

 ❌ 誤った接続:
   [Quest 3] ─── localhost ───> [Quest 3 の中身] (当然 Ollama はいないのでエラー)

 ⭕ 正しい接続:
   [Quest 3] ─── PCのローカルIP (例: 192.168.1.10) ───> [あなたのPC上の Ollama]
```

### 1. パソコンの IP アドレスを調べる
パソコンが自宅のWi-Fiルーターから割り当てられているアドレス（プライベートIPアドレス）を調べます。
- **Windows**: コマンドプロンプトで `ipconfig` を実行し、「IPv4 アドレス」（例: `192.168.1.10`）を確認します。
- **Mac**: ターミナルで `ip config getifaddr en0` を実行して確認します。

### 2. Ollama の公開設定を変更する
Ollamaが「PCの外（Questなど）」からの接続を待ち受けられるように、環境変数 `OLLAMA_HOST` を設定します。
- システム環境変数（または起動コマンド）に、以下を追加します。
  - **変数名**: `OLLAMA_HOST`
  - **変数値**: `0.0.0.0`
  - (※`0.0.0.0` は「外部からの接続をすべて待ち受ける」という意味です)
- 設定後、Ollamaを必ず再起動します。

### 3. アプリ上の ENDPOINT を書き換える
1. Quest 3 のブラウザから、PCのIPアドレスを使ったアプリのテストページ（例: `http://192.168.1.10:3000`）を開きます。
2. アプリ右側パネルの「NEURAL LINK OPTIONS」で、**OLLAMA ENDPOINT** 欄を `http://localhost:11434` から **`http://192.168.1.10:11434`** (あなたのPCのIP) に書き換えて同期します。
